What this is and is not

A JavaScript transcription of stepFn, replay and consumableState from lean/CardanoKeri/Checkpoint.lean, inlined from one core file. The theorems are checked as executable properties on every step you play; the Lean proves them for every step there is.

Numbers are exact up to 2^53 − 1; the Lean's Nat is unbounded, so anything beyond is refused by name rather than rounded.

Not modelled, by the Lean's own statement: cryptography (evidence is a table you decide), validity (D-027, reserved in the datum), the consumer's own threshold check, UTxO mechanics, delegated identities. One AID is played; the registry row is kept for T8.
