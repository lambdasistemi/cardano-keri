# Modules model — #263 reproducible endpoint-board validator

Artifact ceiling: 5,000 bytes and 130 lines.

## Changed responsibilities

### MOD-263-ARTIFACT — deployed board identity

- Owns one compact preproduction blueprint artifact for
  `endpoint_board.endpoint_board.mint`.
- Carries the exact historical compiled program and **DAT-263-PROVENANCE**.
- Is immutable input data, never regenerated by the current onchain build.

### MOD-263-WIRING — test/runtime artifact selection

- Supplies the repository board artifact through a board-specific binding to
  deployment and local-write-path proof runners.
- Continues to supply the current source-built blueprint independently for
  checkpoint validators.
- Has no provider fallback, remote fetch, or live-chain effect.

### MOD-263-DERIVATION — existing production loader

- Existing `loadBlueprint` and `deriveBoardScript` decode and derive the board
  policy from repository bytes without an alternate test-only hash algorithm.
- A malformed, missing, duplicated, or wrongly titled validator fails closed.

### MOD-263-MANIFEST-PROOF — deployed equality

- Executes the formerly pending manifest case using **MOD-263-WIRING** and
  **MOD-263-DERIVATION**.
- Compares the derived artifact with the frozen board manifest.
- Does not modify or bypass production `consumerErrors`.

### MOD-263-WRITE-PROOF — board verb completion

- Seeds the deployed board reference script from **MOD-263-ARTIFACT**.
- Completes post, update, and retire read-set/build proofs deferred by #240.
- Retains local-only routing, one-snapshot behavior, and fail-closed decoding.

### MOD-263-GATE — lasting falsifiable proof

- Executes exact program-length, digest, production-derivation, frozen-policy,
  manifest, board-verb, and no-weakening checks.
- Is proven able to fail by a one-nibble program perturbation before accepting
  the restored tree.
- Includes `ci-onchain` even though onchain sources are fenced.

## Dependency direction

- **EDGE-263-01:** wiring → repository board artifact.
- **EDGE-263-02:** manifest proof → wiring + existing production derivation +
  frozen manifest.
- **EDGE-263-03:** write proof → wiring + existing local composition harness.
- **EDGE-263-04:** current checkpoint blueprint does not supply or overwrite
  the recovered board artifact.
- **EDGE-263-05:** artifact/proofs have no dependency on a provider or live
  node.

## Promotion decision

- **PROMOTE-263-01:** promote the exact deployed board program to a repository
  deployment artifact because multiple test/operator consumers require the
  same stable production identity.
- **PROMOTE-263-02:** do not promote the historical full blueprint; validators
  unrelated to the deployed board would expand the frozen surface without a
  consumer.
- **PROMOTE-263-03:** retain the current blueprint as source-build evidence,
  not as an alias for the deployed board artifact.
